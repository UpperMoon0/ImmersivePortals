# Immersive Portals - CE 6.0.8

## Added

- Real NeoForge GameTest against Sable 2.0.5 verifying the portal collision hook runs exactly once, vanilla movement is applied, and Sable collision state is populated.
- Deterministic bytecode-structure tests for the collision wrapper chain.
- Automated GitHub and CurseForge release publishing workflows.

## Changed

- Updated NeoForge development baseline to 21.1.228 (required by Sable 2.0.5).
- Clean-runner dependency isolation so Sable's embedded libraries are not redundantly resolved from development repositories.

## Fixed & Optimized

- Prevents duplicate portal collision processing when Sable is installed by selecting a single collision-wrapper owner.
- Keeps normal Immersive Portals collision behavior unchanged when Sable is absent.
- Makes the Sable compatibility injection fail visibly if a future Sable update changes the expected collision target.

Sable remains optional for users who do not need moving-body portal compatibility.
