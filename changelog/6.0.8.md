# Immersive Portals - CE 6.0.8

## Changes

- Prevents duplicate portal collision processing when Sable is installed by selecting a single collision-wrapper owner.
- Keeps normal Immersive Portals collision behavior unchanged when Sable is absent.
- Makes the Sable compatibility injection fail visibly if a future Sable update changes the expected collision target.
- Adds a real NeoForge GameTest against Sable 2.0.5 that verifies the portal hook runs exactly once, vanilla movement is applied, and Sable collision state is populated.
- Adds deterministic bytecode-structure tests for the collision wrapper chain.
- Updates the NeoForge development baseline to 21.1.228, required by Sable 2.0.5.
- Adds clean-runner dependency isolation so Sable's embedded libraries are not redundantly resolved from development repositories.
- Adds automated GitHub and CurseForge release publishing.

Sable remains optional for users who do not need moving-body portal compatibility.
