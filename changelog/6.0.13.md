# Immersive Portals - CE 6.0.13

Minecraft 1.21.1 / NeoForge 21.1.228+ / Java 21

## Fixed

- Recover failed portal chunk promotions while their tickets remain active. Failed neighbor-range results are requeued with a one-second game-time cooldown; vanilla accessible/block/entity-ticking futures are recreated only when failed and their current ticket permits that status. Pending and successful futures retain their identity; exceptional I/O remains an error. The player delivery queue retains unloaded chunks until actual block/light packets can be sent. Retry queue cleanup removes retained tickets too.
- Make Forgified Fabric networking 4.2.2+a92978fd19 receiver registration safe across both flows of one payload and distinct local listeners. Concurrent maps publish native handlers and receivers to network reads. A per-receiver-map registration lock preserves upstream duplicate return values and callback construction; dispatch and removal stay lock-free. Unsupported networking versions fail with a precise supported-version message.

## Verification and release speed

- Start real-pack tests after core/login checks while fixture tests continue. Every existing graphical configuration and assertion remains required.
- Reuse the exact main-tested release jar only after all 35 CI checks succeeded for the tagged commit, with matching repository/run attempt, artifact origin, version and checksum. Ineligible evidence verifies afresh; corrupt selected artifacts block publication.
- Show live scene/readiness changes and minute heartbeats without extending deadlines or counting these messages as game progress.
- Real-pack checks unload a client End chunk and inject failed server block/entity-ticking futures during nested reload. Recovery, real resend, full chunk data and unchanged portal/depth pixel assertions must pass.

The renderer versions and scoped Create/Flywheel fallback described in [6.0.12](6.0.12.md) remain supported. See the [issue acceptance map](../docs/issue-resolution-6.0.13.md) for the retained regressions and required native lanes.
