# Immersive Portals - CE 6.0.10

Minecraft 1.21.1 / NeoForge / Java 21

## Fixed

- Fixed Veil 4.3.2 graphics errors when labeling cached buffers and vertex arrays or uploading particle meshes. The graphics cache creates initialized objects on OpenGL drivers supporting direct state access and retains the existing allocation path on older drivers.
- Prevented Create 6.0.10 item drains from dropping a second copy of their held item during Sable assembly. The compatibility tag uses Sable's silent-removal path while retaining the saved inventory in the assembled drain.
- Fixed the Sable verification fixtures: physics tests run near the origin to avoid single-precision coordinate loss, gravity expectations include the configured drag over a complete simulation interval, and inventory comparisons use snapshots taken immediately before assembly, after sided insertion and the intervening machine tick. Insertion respects slot validation instead of forcing items into non-persistent visual connector slots.

## Verification

- Added a real-client graphics regression checking 1,001 cached buffers and vertex arrays, cache refill, preserved render bindings, immediate debug labels, and an unbound buffer upload.
- Core verification now fails if any optional GameTest fails.
- Added a required native Sable/Create regression verifying that a loaded item drain retains exactly one item and produces no dropped copy during assembly.
- Sable fixture adjustments are enabled only in the development GameTest server. Their mixins and configuration are excluded from the release JAR.
