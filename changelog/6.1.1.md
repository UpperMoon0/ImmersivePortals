# Immersive Portals - CE 6.1.1

Minecraft 1.21.1 / NeoForge 21.1.228+ / Java 21

## Fixed

- Prevent detached Sable riders from free-falling while authoritative dimension, acknowledgement and seat-attachment packets are pending. Suspend only the captured local player's movement prediction, preserving authoritative updates and the existing 100-tick synchronization limit. Reattachment ends the movement hold while retaining the pending-acknowledgement watchdog; unrelated players, seats or dimensions invalidate the handoff permanently.
- Support structurally compatible newer Forgified Fabric Networking API modules instead of requiring exactly 4.2.2+a92978fd19. Validate the fields, receiver method descriptors and redirect sites used by the registration patches. Preserve registration synchronization, duplicate handling, callback dispatch and setup-state restoration. Verified modules include TxniLib's 4.3.0+5c124ecf19 and 4.3.1+7e3d421f19. The latter requires NeoForge 21.1.248 or newer. Fixes issue #29.

## Verification

- Add native delayed-acknowledgement movement, lifecycle invalidation, post-acknowledgement missing-seat timeout, 20 repeated handoffs, cleanup-event and actual disconnect regressions. Keep the existing spatial-continuity, overlap, gravity, camera, dismount and remote-observer assertions.
- Require UDP and TCP with the bundled, TxniLib and newer networking modules, plus two newer-module lanes with 30 ms delay, 10 ms jitter and 0.5% random packet loss. Require recorded traffic through the impairment queue and every native result marker.
- Retain all 30 renderer/shader configurations. Release evidence now requires all 41 CI jobs from the exact commit and run attempt.

The lifecycle injections and bounded repetition test do not claim an hours-long multiplayer soak. See [rider regression coverage](../docs/compat/sable-rider-handoff.md) and [networking compatibility](../docs/compat/forgified-fabric-networking.md) for details.

This patch retains the stationary miniature prototype from 6.1.0; it does not complete issue #24's moving-miniature milestone.
