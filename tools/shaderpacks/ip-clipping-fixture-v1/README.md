# Portal clipping fixture v1

Repository-owned, Apache-2.0 shaderpack. No downloaded assets. The verification
runner records a SHA-256 over names and contents. Explicit solid, cutout, water,
entity, block-entity and particle programs prevent fallback from hiding missing
clipping hooks. Flat diagnostic red for non-solid programs makes leakage visible;
solid retains texture colors so the lime destination is an independent oracle.
This is a regression fixture, not a representative artistic shaderpack.
